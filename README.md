# 🐦 Flappy Bird en Python.
recuerda darme creditos

Clon educativo de Flappy Bird hecho con **Python + Tkinter**, sin Pygame.

## Características

- 🖥️ Pantalla completa.
- 📐 Adaptación automática a distintas resoluciones.
- 🐦 Física sencilla y salto.
- 🟩 Tuberías aleatorias.
- 🏆 Sistema de puntuación.
- 💥 Detección de colisiones.
- 🔄 Reinicio.
- 🚫 Sin dependencias externas.

## Requisitos

- Python 3.x
- Tkinter (normalmente incluido en Python para Windows).

## Ejecutar

```bash
python flappy_bird.py
```

En Windows también puedes usar:

```bash
py flappy_bird.py
```

## Controles

| Tecla | Acción |
|---|---|
| `ESPACIO` | Saltar |
| `R` | Reiniciar después de perder |
| `ESC` | Salir de pantalla completa |
